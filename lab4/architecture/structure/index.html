    Структура проекта¶

    Lr4/
├── src/
│   ├── api/
│   │   └── client.js          # Настройка Axios и обработка токенов
│   ├── stores/
│   │   ├── auth.js            # Хранение состояния аутентификации
│   │   └── reference.js       # Справочные данные (классы, предметы и т.д.)
│   ├── router/
│   │   └── index.js           # Конфигурация маршрутов
│   ├── views/
│   │   ├── Login.vue          # Страница входа
│   │   ├── Register.vue       # Страница регистрации
│   │   ├── Home.vue           # Главная страница
│   │   ├── Teachers.vue       # Управление учителями
│   │   ├── Students.vue       # Управление учениками
│   │   ├── Classes.vue        # Управление классами
│   │   ├── Schedules.vue      # Управление расписанием
│   │   ├── Grades.vue          # Управление оценками
│   │   ├── Info.vue           # Статистика
│   │   └── Reports.vue         # Отчеты
│   ├── plugins/
│   │   └── vuetify.js         # Конфигурация Vuetify
│   ├── App.vue                # Корневой компонент
│   └── main.js                # Точка входа приложения
├── package.json               # Зависимости проекта
└── vite.config.js            # Конфигурация Vite

    Описание директорий¶

    src/api/¶

    Содержит конфигурацию HTTP клиента (Axios) с настройкой базового URL, обработкой токенов и ошибок.

    src/stores/¶

    Pinia stores для управления состоянием: - auth.js - состояние аутентификации - reference.js - справочные данные

    src/router/¶

    Конфигурация маршрутизации приложения с защитой маршрутов.

    src/views/¶

    Vue компоненты страниц приложения. Каждый компонент отвечает за отображение и управление определенным разделом приложения.

    src/plugins/¶

    Плагины Vue, включая конфигурацию Vuetify.
